# Quick Access image resources

The PNG files in this directory are imported from the Quick Access Manager
Python plugin's `remaster/resources` directory. They retain the plugin's
GPL-3.0 license and are embedded in the native Quick Access docker binary.

Keep the directory and file names stable: migrated profiles refer to the
default icons by file name.
