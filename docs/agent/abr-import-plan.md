# Photoshop brush (ABR) import plan - historical pointer

The mixed plan and implementation record has been separated by responsibility:

- [Current maintenance reference](abr-import.md): supported data, parser limits,
  conversion rules, resource identities, reload, tags, tests and manual checks.
  Use this before changing ABR import.
- [Development history](wiki/history/abr-import-development.md): the complete
  original investigation, staged plan, implementation results and verification
  preserved as of 2026-10-16.
- [User guide](../photoshop-brushes.md): import workflow and visible limitations.

This path remains for existing references. Old stage names and quoted passages
are in the history. The initial unsupported-settings list and interim texture
inversion rules were superseded by later implementation; use the maintained
reference for new work. Archived plans do not authorize additional features.
