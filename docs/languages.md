# Interface languages

Solstice starts in English. To change the language, choose **Settings >
Switch Application Language**, pick a language, and restart Solstice.

## Simplified Chinese

The Simplified Chinese interface (简体中文) is fully translated, including
the features Solstice adds. The translation of Solstice's own text is
machine-made and has not been reviewed by a native speaker yet: if a label
reads oddly or is cut off, please report it on the
[issue tracker](https://github.com/udtren/Solstice/issues), with a
screenshot if you can.

Some names stay in English on purpose, so that they match the guides, the
website and screenshots: Solstice, Quick Access, Quick Access Palette, Quick
Brush Adjustments, HueSVC, Rest Note, Asset Library, Vision ML, Puppet
Warp, Layer Comps, Brush Stroke Layer, and the filters Solstice adds (such
as Film Grain, Color Filter, Color Reference and Line Art Extraction).

The dialog that offers to import a Krita profile on the first start appears
before the language setting is read. It is shown in English, Japanese or
Simplified Chinese, following Krita's language setting or, without one, the
Windows display language.

## Other languages

Other languages use the translations Solstice inherited from Krita. The
features Solstice adds, and text that changed when Krita became Solstice,
are shown in English in those languages.

G'MIC-Qt translates its own dialog; Qt's standard buttons and file dialogs
follow the chosen language too.
